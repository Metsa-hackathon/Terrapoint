Terrapoint

API dokumentatsioon

Terrapointi avalik API koondab Eesti katastri-, metsa- ja ruumiandmeid. Masinloetav täielik leping koos parameetrite ja vastuseskeemidega on OpenAPI JSON-failis.

Põhiotspunktid

GET /api/health
Rakenduse tervis ja vahemälu koondolek.
GET /api/address/{q}
Aadressiotsingu katastrivalikud.
GET /api/cadastre/objects/{adob_id}
Kaardiobjekti tunnuse seostamine katastritunnusega.
GET /api/search/{kataster_nr}
Kinnistu põhiandmed, arvutuslikud stsenaariumid, allikate olekud ja kaardikihid.
GET /api/map-context/{kataster_nr}
Valitud kaarditeemade allikaolekud ja kinnistuga kattuvad objektid.
GET /api/export/eudr/{kataster_nr}
Geolokatsiooni lähtefail; mitte EUDR vastavustõend ega hoolsuskohustuse deklaratsioon.
POST /api/chat
Serveri allkirjastatud kinnistuandmetega piiratud AI-küsimus.

Kasutamine

Katastritunnus peab vastama ametlikule kujule, näiteks 78404:409:0113. Vastuste meta-, sources_complete- ja unavailable_sources-väljad eristavad täielikku kontrolli, osalist vastust ja allikakatkestust.

Piirangud, toetused, väärtusvahemikud, süsinikuvaru ja EUDR-väljavõte on otsustustoe sisendid, mitte load, vastavustõendid, turuväärtus ega kohapealne ekspertiis.
